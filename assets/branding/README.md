The generated artwork is retained at its original resolution. Platform icon sizes are produced by `python tools/generate_app_icons.py` using Pillow. This sizes the approved artwork without changing its design. Android retains the existing `@mipmap/ic_launcher` manifest reference; iOS/macOS retain their existing AppIcon catalogs; web manifest retains its icon paths; Windows retains its existing ICO resource path.

Only Android is built on this Windows workspace. The other platforms' image assets are updated, but their application builds have not been verified. An installed Android app needs the newly built APK installed before its launcher icon changes.
